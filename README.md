# 🏜️ TurismoIca

> Sitio web estático de turismo para la región de Ica, Perú — desarrollado como proyecto académico de 7.º ciclo.

---

## ✨ Vista general

**TurismoIca** es una plataforma web informativa y visual diseñada para promover los destinos turísticos más emblemáticos de la región de Ica: el oasis de Huacachina, las Líneas de Nazca, la Reserva de Paracas, las Islas Ballestas y las bodegas pisqueras de la zona.

El proyecto pone en práctica conceptos modernos de diseño web: sistema de diseño con variables CSS, layouts responsivos con Grid y Flexbox, tipografía editorial y experiencia de usuario cuidada en cada página.

---

## 📄 Páginas

| Página | Descripción |
|---|---|
| `index.html` | Landing page con hero, estadísticas, destinos y testimonios |
| `nosotros.html` | Historia de la agencia, equipo, valores y línea de tiempo |
| `servicios.html` | Catálogo de 8 tours con filtros, precios y tabla comparativa |
| `galeria.html` | Galería fotográfica con filtros por destino |
| `contacto.html` | Formulario de contacto, mapa, horarios y FAQ |

---

## 🛠️ Tecnologías Usadas

- **HTML5** semántico
- **CSS3** — variables, Grid, Flexbox, `clamp()`, `backdrop-filter`
- **JavaScript** vanilla — filtros de galería, menú móvil, validación de formulario
- **Google Fonts** — Playfair Display + Inter
- **Unsplash** — fotografía real de alta resolución

No se utilizan frameworks, librerías externas ni sistema de build. Todo corre directamente en el navegador.

## 🎨 Sistema de diseño

```
Terra     #C05A28   →  color primario (dunas, desierto)
Gold      #D4A040   →  acento dorado
Sky       #2660A4   →  azul océano (Paracas)
Green     #22724A   →  verde naturaleza
Sand      #F3E8CC   →  fondo cálido
```
